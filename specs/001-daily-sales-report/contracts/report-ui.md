# Contract: رابط کاربری گزارش روزانه

## مسیر

- `/admin/reports` در پنل مدیریت، با آیتم منوی «گزارش روزانه» (آیکون `FileChartColumn` از lucide-react) بعد از
  «فاکتورها». پشت همان گارد `AdminLayout` است.
- پارامتر اختیاری `?day=YYYY-MM-DD` (میلادی). نبودش یعنی امروزِ تهران. لینک قابل اشتراک است.

## بخش‌های صفحه (به ترتیب)

1. **انتخاب روز**: تقویم شمسی (`react-day-picker/persian`، `faIR`، راست‌به‌چپ). روزهای بعد از امروزِ
   تهران غیرفعال‌اند. دکمه‌های «دیروز» و «امروز».
2. **سرتیتر**: «گزارش فروش — <تاریخ شمسی کامل>»، و برای امروز «تا ساعت hh:mm» با دکمهٔ
   «به‌روزرسانی».
3. **کارت‌های جمع**: فروش کارتی (مبلغ + تعداد فاکتور)، فروش نقدی (مبلغ + تعداد)، جمع کل. ارقام
   فارسی، جداکنندهٔ هزارگان و «تومان».
4. **بلیط‌ها**: جمع کل و جدول نوع → تعداد. ردیف «نامشخص (فروش‌های قدیمی)» فقط اگر بیش از صفر باشد.
5. **تراکنش‌های نیازمند بررسی**: بررسی‌نشده (تعداد + مبلغ)، بررسی‌شده (تعداد + مبلغ)، «آخرین ارسال
   از کیوسک: …»، توضیح «مبلغ این تراکنش‌ها در جمع فروش نیامده»، و لینک «مشاهدهٔ فهرست» به
   `/admin/reports/review?day=…`. اگر `review === null`: «در دسترس نیست — کیوسک هنوز به گزارش وصل
   نشده».
6. **دکمهٔ «چاپ گزارش»**.

## فهرست تراکنش‌های نیازمند بررسی — `/admin/reports/review`

- جدول: زمان، مبلغ، علت، شمارهٔ فاکتور، شمارهٔ مرجع، کیوسک، وضعیت بررسی. شمارهٔ کارت ندارد.
- برای ردیف بررسی‌نشده: دکمهٔ «بررسی شد» با یادداشت → `review_pos_transaction`.

## چاپ (A4 عمودی)

- `@media print`: منو، هدر پنل، دکمه‌ها و تقویم پنهان. فقط بخش `#daily-report-print` چاپ می‌شود.
- **سربرگ**: «موزهٔ افتخارات کشتی ایران — گزارش فروش روزانه»، تاریخ شمسی روز، «چاپ: <تاریخ و ساعت
  تهران>»، «چاپ‌کننده: <ایمیل یا حالت بدون رمز>».
- **بدنه**: همان اعداد بخش‌های ۳ تا ۵، بدون لینک.
- **پاورقی**: دو کادر امضا: «تحویل‌دهنده» و «تحویل‌گیرنده».
- باید روی یک برگه جا شود (تا ۱۰ نوع بلیط).

## حالت‌ها

| State | Display |
| --- | --- |
| loading | اسکلت کارت‌ها |
| no sales | صفرها + «در این روز فروشی ثبت نشده» |
| function missing | «گزارش روزانه هنوز روی دیتابیس فعال نشده است» (بدون عدد) |
| network error | پیام + «تلاش دوباره» (بدون عدد) |
| no access | «دسترسی ندارید» |
