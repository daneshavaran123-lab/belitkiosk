# طراحی: شیشهٔ مایع (Liquid Glass)

ظاهر کیوسک و پنل مدیریت یک زبان طراحی واحد دارد: سطح‌های شیشه‌ای نیمه‌شفاف روی تصویر تالار موزه و نورهای
برنزی/آبی که آرام جابه‌جا می‌شوند. همهٔ آن در `src/styles.css` است؛ در کد صفحه‌ها فقط نام کلاس‌ها را
می‌گذارید.

## سطح‌ها

| کلاس           | کاربرد                                               |
| -------------- | ---------------------------------------------------- |
| `glass`        | کارت و پانل معمولی، سربرگ، منوی کناری                |
| `glass-bronze` | کارت‌های اصلی کیوسک (مایهٔ مس و آبی موزه)            |
| `glass-strong` | پنجره، منو، پاپ‌اور؛ خوانایی بیشتر روی هر پس‌زمینه   |
| `glass-well`   | فرورفته: فیلد ورودی، خلاصهٔ مبلغ، هر چیز «داخل» کارت |
| `glass-chip`   | دکمهٔ ثانویه، برچسب، کلید شماره‌گیر                  |
| `glass-amber`  | هشدار و وضعیت نیازمند توجه                           |
| `btn-liquid`   | دکمهٔ اصلی (برنز مایع)؛ هر صفحه فقط یک دکمهٔ اصلی    |

متن‌ها روی شیشه سفید یا `text-white/70`‌اند؛ عنوان‌های مهم `text-bronze-gradient`.

## پس‌زمینه

`<KioskBackdrop dim="soft|normal|deep" />` تصویر، سایهٔ ملایم و نورها را می‌سازد (`PageShell` و پنل مدیریت
خودشان آن را می‌گذارند). بدون پس‌زمینه شیشه چیزی برای شکستن نور ندارد و تخت دیده می‌شود.

## قاعده‌ها

- **لمس**: هدف لمسی دست‌کم ≈ ۵۶ پیکسل (روی کیوسک `h-14` به بالا)؛ کلاس `touch-btn` فشردن را با
  انیمیشن فنری نشان می‌دهد.
- **اعداد فارسی**: برای هر عدد نمایش‌داده‌شده از `formatNumber` / `formatToman` (`src/lib/money.ts`) استفاده
  کنید، نه `{n}` خام.
- **حرکت**: همهٔ انیمیشن‌ها با `prefers-reduced-motion` خاموش می‌شوند؛ نورها فقط `transform` را عوض می‌کنند
  تا روی کیوسک سبک بمانند.
- **فونت**: وزیرمتن از خود برنامه بارگذاری می‌شود (`public/fonts`، مجوز OFL کنارش است)؛ به اینترنت نیاز
  نیست.
- **پیام‌ها**: `sonner` با همین شیشه استایل شده؛ روی کیوسک عمودی زیر سربرگ می‌نشیند.
- ظاهر چاپ گزارش (`@media print`) و قالب رسید جداست و به این سطح‌ها وابسته نیست.
