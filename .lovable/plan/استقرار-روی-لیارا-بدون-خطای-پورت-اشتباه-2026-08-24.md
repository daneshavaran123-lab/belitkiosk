# استقرار روی لیارا بدون خطای «پورت اشتباه»

خطای لیارا به این معناست که سرویس شما روی `0.0.0.0` و روی پورتی که لیارا تعیین می‌کند (متغیر `PORT`) گوش نمی‌دهد. پروژه در حال حاضر برای اجرا روی Cloudflare Workers ساخته می‌شود (خروجی build یک worker است، نه یک سرور Node که پورت باز کند). به همین دلیل لیارا هیچ پورتی پیدا نمی‌کند و همان صفحه‌ی خطا را نشان می‌دهد.

## راه‌حل

خروجی build را برای «سرور Node» بسازیم و یک اسکریپت start اضافه کنیم که روی `0.0.0.0:$PORT` بالا بیاید.

### ۱. هدف build برای Node
- در `vite.config.ts` پیکربندی nitro با preset `node-server` اضافه شود (فقط برای build تولیدی؛ پیش‌نمایش لاولیبل بدون تغییر می‌ماند و همچنان روی Cloudflare اجرا می‌شود).
- خروجی در `.output/server/index.mjs` تولید می‌شود.

### ۲. اسکریپت اجرا
- افزودن `"start": "node .output/server/index.mjs"` به `package.json`.
- تنظیم `HOST=0.0.0.0` و استفاده از `PORT` لیارا (nitro هر دو متغیر را می‌خواند).

### ۳. فایل‌های لیارا
- `liara.json` با پلتفرم `node`، نسخه‌ی Node 22، و دستور build.
- `.dockerignore` / تنظیم `node.timezone` و مسیر static.

### ۴. متغیرهای محیطی روی لیارا
باید در پنل لیارا (بخش متغیرها) این‌ها ست شوند تا اتصال به بک‌اند کار کند:
- `VITE_SUPABASE_URL`، `VITE_SUPABASE_PUBLISHABLE_KEY`، `VITE_SUPABASE_PROJECT_ID`
- `SUPABASE_URL`، `SUPABASE_PUBLISHABLE_KEY`
(مقادیر همان‌هایی است که در فایل `.env` پروژه وجود دارد.)

### ۵. مستندات
افزودن بخش «استقرار روی لیارا» به `README.md` با مراحل دقیق: `npm run build` → `liara deploy` → بررسی لاگ‌ها.

## نکته‌ی مهم درباره‌ی کارت‌خوان
سرویس پل کارت‌خوان (`pos-bridge`) روی `127.0.0.1` همان کیوسک اجرا می‌شود؛ با استقرار روی لیارا هم بدون تغییر کار می‌کند، چون درخواست پرداخت از مرورگر کیوسک به لوکال‌هاست همان دستگاه می‌رود. فقط اگر سایت روی HTTPS باشد، مرورگر ممکن است درخواست HTTP به لوکال‌هاست را محدود کند؛ در آن صورت باید Chrome کیوسک با فلگ اجازه‌ی محتوای ناامن برای دامنه‌ی شما اجرا شود (به اسکریپت `scripts/launch-kiosk.bat` اضافه می‌شود).

## جزئیات فنی
- `vite.config.ts`: `defineConfig({ nitro: { config: { preset: process.env.NITRO_PRESET ?? 'cloudflare_module' } } })` تا با `NITRO_PRESET=node_server` بیلد Node ساخته شود و پیش‌فرض لاولیبل دست‌نخورده بماند.
- `liara.json`: `{ "platform": "node", "port": 3000, "node": { "version": "22" } }` — nitro مقدار `PORT` را از محیط می‌خواند و روی `0.0.0.0` گوش می‌دهد.
- بدون تغییر در منطق برنامه، صفحات، یا دیتابیس.
